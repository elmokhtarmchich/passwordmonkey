# Privacy Policy

## Overview

At PasswordMonkey, we take privacy seriously. This policy explains how we handle your data and what you can expect when using our password generator.

## Data Collection

### What We Don't Collect

PasswordMonkey is designed with privacy as a core principle. We do NOT:

- Collect any personal information
- Store passwords or password generation data
- Use cookies or tracking technologies
- Transmit data to third-party servers
- Require account registration
- Store IP addresses or location data
- Track your browsing behavior

### What We Do Collect

We collect minimal data only for site improvement:

- Anonymous usage statistics (page views, error reports)
- Basic browser information for compatibility
- No personally identifiable information

## How Passwords Are Generated

### Client-Side Processing

All password generation occurs entirely in your browser using:

- Web Crypto API for cryptographically secure random number generation
- Local JavaScript processing
- No server communication for password operations

### Data Flow

1. You set password parameters (length, character types)
2. The browser generates random values using Web Crypto API
3. The password is created locally in your browser
4. The password is displayed on your screen
5. **No password data is ever transmitted to any server**

## Security Measures

### Technical Protections

- HTTPS encryption for all site traffic
- Security headers (X-Content-Type-Options, X-Frame-Options, X-XSS-Protection)
- No sensitive data in URLs or forms
- Regular security audits and updates

### Password Security

- Cryptographically secure random generation
- No password storage or caching
- Immediate memory clearance after generation

## Third-Party Services

### What We Use

- Google Analytics (anonymized, opt-out available)
- CDN services for static assets
- Security scanning services (Norton, Cloudflare, Sucuri)

### What We Don't Share

- No password data
- No personal information
- No browsing history
- No usage patterns linked to individuals

You have the right to:

- Opt out of analytics tracking
- Access information about our data practices
- Report privacy concerns

### Contact Us

For privacy-related questions or to exercise your rights, please contact us through our website.
