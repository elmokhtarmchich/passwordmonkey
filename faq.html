Using the generator

Is it safe to use the PasswordMonkey generator?

Yes. All password generation happens in your browser using the Web Crypto API.

PasswordMonkey never sees, stores, or transmits your passwords. Nothing leaves your device. Randomness comes from your device's hardware random number generator via crypto.getRandomValues().

Does PasswordMonkey store or see my passwords?

No. PasswordMonkey never receives your passwords.

Generation is entirely local to your device. We don't log, store, or transmit generated passwords. No network request carries them.

How long should my password be?

Use 15 characters or more; 16 or more is recommended.

NIST SP 800-63B-4 sets a 15-character minimum for single-factor passwords and allows at least 64. Longer passwords are exponentially harder to crack. If a site limits length, use the maximum it allows and a unique password for that site.

Learn more about why use random passwords

Do I need symbols in my password?

No. Length and uniqueness matter most; symbols are optional.

NIST removed composition rules. You don't need mixed uppercase, lowercase, numbers, and symbols. A long password or passphrase works fine without symbols. If a site requires symbols, add them — but don't rely on them for strength.

What if a site limits password length or rejects symbols?

Use the maximum length the site allows.

If a site caps length or rejects symbols, generate the longest password it accepts using letters and numbers. Length still matters most. Pair it with a password manager so you don't have to remember it.

Random password or passphrase?

Both work.

A long random password and a passphrase of several random words are both strong. Store either in a password manager so you only need to remember one master password.

What do the password strength indicators mean?

The indicator shows entropy in bits: weak (<32), fair (32-64), good (64-128), strong (128+).

PasswordMonkey calculates strength from the character set size and length. Higher entropy means harder to crack. Aim for 128+ bits for your most important accounts.

Is PasswordMonkey safe to use?

Yes. All generation happens in your browser; nothing is stored or transmitted.

Passwords are created locally via the Web Crypto API and never sent to our servers. The page uses GTM and AdSense for aggregate traffic measurement — neither sees your generated passwords.

Where should I save my passwords?

In a password manager.

Use a browser-built-in manager or a dedicated password manager. Never store passwords in notes apps, spreadsheets, email to yourself, or screenshots — those aren't designed to protect secrets.

Is it safe to save passwords in my browser?

Yes, browsers can save passwords.

Browsers store encrypted credentials on your device. One caveat: entries are filed under the page's origin (passwordmonkey.org for this site), not under the target site the password is for.

Learn more about saving passwords to browser

What is a password manager?

An app that stores your passwords in an encrypted vault.

You unlock it with one strong master password. The manager generates, saves, and autofills passwords for every site, so you never reuse passwords and never memorize dozens.

Why does my browser file the entry under passwordmonkey.org?

Browsers save credentials under the page's origin.

When you save a password while on passwordmonkey.org, the browser files it under our origin, not under the site the password is actually for. Browser credential storage is tied to the domain you're visiting when you save.

Can I reuse a password?

No. Use a unique password for every account.

If one account is compromised and you reused that password elsewhere, all those accounts are at risk. A password manager makes unique passwords practical by remembering them for you.

Losing access

What if I forget a password?

Use the site's "forgot password" reset flow.

Most sites reset by email. If you saved it in a password manager, check there first. Never reuse an old password when resetting — generate a new random one.

Learn more about lost password don't panic

What if I lose my phone?

Use your password manager on another device, or your recovery codes.

Install your manager on a new device and sign in with your master password. Keep recovery codes and your emergency kit safe (paper, locked drawer) so you can regain access.

Learn more about recovery kit

What if I forget my password manager's master password?

It may be unrecoverable.

Bitwarden cannot reset a forgotten master password. 1Password uses an Emergency Kit (Secret Key) and recovery codes. Apple needs a trusted device passcode, recovery contact, or recovery key. No "forgot master password" reset exists — that's the encryption's purpose.

After a breach

How do I know if a password was exposed?

Chrome warns about exposed passwords; Edge has Password Monitor.

Your password manager may also monitor for breaches and alert you if a saved password appears in a known breach. Act on those warnings promptly.

What do I change first after a breach?

Change the breached password first.

Then change any other account where you reused the same password. NIST says change on evidence of compromise — not on a fixed schedule. Use unique random passwords going forward.

Do I need two-step verification?

Yes, where available.

Two-step verification adds a second check beyond your password — an app code or security key. Even if your password is stolen, the second step protects your account.
