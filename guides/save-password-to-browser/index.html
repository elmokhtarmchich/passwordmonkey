Save Passwords to Your Browser

Last updated: October 2026

Your browser can save passwords for you. Here's how to do it, browser by browser. Honest note: the save prompt may not appear — if it doesn't, you can add the entry manually.

Chrome

  1. Go to the site and log in
  2. When Chrome offers to save the password, click Save
  3. If the prompt doesn't appear: go to chrome://password-manager/passwords, click Add, and enter site, username, and password

Edge

  1. Go to the site and log in
  2. When Edge offers to save, click Save
  3. If the prompt doesn't appear: go to Settings > Passwords and autofill > Microsoft Password Manager

Firefox

  1. Go to the site and log in
  2. When Firefox offers to save, click Save
  3. If the prompt doesn't appear: go to about:logins > Create new login [VERIFY menu names]

Safari / iCloud

  1. Go to the site and log in
  2. When Safari offers to save, click Save Password
  3. Manage saved passwords in the Passwords app or Settings > Passwords [VERIFY menu names]

Samsung Internet / Samsung Pass

  1. Samsung Pass is part of Samsung Wallet and works with Samsung Internet [VERIFY]
  2. Samsung Internet can also use Google autofill [VERIFY menu names]

Opera / Brave / Vivaldi

  1. These Chromium-based browsers support PasswordCredential storage
  2. Look for the save prompt when logging in, or check the browser's password settings

Important notes

  • The save prompt may not appear on every site — that's normal
  • Entries are filed under the page's origin (e.g., passwordmonkey.org), not the target site
  • Internal chrome:// and edge:// URLs cannot be opened from a web page — use the Copy address buttons above
