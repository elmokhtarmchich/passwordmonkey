Password Advice That Changed

Last updated: October 2026

Old password advice said: change every 90 days, use symbols, mix character types. Modern guidance from NIST says otherwise. This guide explains what changed, what stayed the same, and why — so you can follow current best practices instead of outdated rules.

What changed

Modern standards like NIST SP 800-63B-4 rewrote the rules. The old checklist approach is gone. Here is what replaced it:

  • No forced periodic change: change on evidence of compromise, not on a schedule. Research shows forced changes lead to weaker passwords, because people make small, predictable edits.
  • No composition rules: symbols and mixed character types are not required. Length and uniqueness matter most. A long random phrase beats a short clever one.
  • Length matters most: 15-character minimum, 64+ allowed. Longer passwords are exponentially harder to crack, far more than adding a symbol.
  • Password managers and paste must be allowed: sites should not block password managers or paste. Blocking them pushes users toward reuse.
  • Screen against common and breached passwords: check new passwords against lists of known-compromised passwords and reject matches.

What stayed the same

Some fundamentals never changed. The core goals of password security remain:

  • Use unique passwords for every account, so one breach does not spread.
  • Longer passwords are exponentially harder to crack — length is still king.
  • Randomness matters: avoid patterns and personal information that attackers can guess.
  • Store passwords in a password manager instead of your memory or a notebook.

Old advice vs new advice

Old advice New advice (NIST SP 800-63B-4)
Change every 3-6 monthsChange only on evidence of compromise
Require symbols, uppercase, numbersNo composition rules; length and uniqueness matter most
Minimum 8-12 charactersMinimum 15 characters, allow 64+
Memorize all your passwordsUse a password manager

Why the change

The shift came from research, not opinion. Forced periodic changes led to weaker passwords — people made small, predictable changes like "Password1" to "Password2". Composition rules did not significantly improve strength; length did. Password managers made unique passwords practical, so memorization was no longer the bottleneck. NIST SP 800-63B-4, finalized in August 2025, reflects this modern research and is now the baseline for digital identity guidance.

What this means for you

  • Use 15+ characters; 16 or more is recommended.
  • Use unique passwords for every account.
  • Store them in a password manager.
  • Change a password only if you suspect a breach, not on a schedule.
  • Symbols are optional — do not let a site's weak rules force you into a shorter password.
