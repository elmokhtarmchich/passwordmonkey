# Frequently Asked Questions

Find answers to common questions about PasswordMonkey, password security, and best practices for creating strong passwords.

## How to Use PasswordMonkey

### Q: How do I generate a password?
A: Simply set your desired password length (4-50 characters), choose which character types to include (uppercase, lowercase, numbers, symbols), and click "Generate Password". The tool will create a cryptographically secure random password instantly.

### Q: Can I customize the password generation?
A: Yes! You can customize:
- Password length (4-50 characters)
- Character types (uppercase, lowercase, numbers, symbols)
- Exclude ambiguous characters (i, l, 1, |, o, O, 0)
- Exclude similar-looking characters (0, O, o, 1, l, I)

### Q: How do I copy the password?
A: Click the "Copy" button next to the generated password. The password will be copied to your clipboard, and you'll see a confirmation tooltip.

### Q: Can I generate a QR code for the password?
A: Yes, click the QR code button to generate a scannable QR code containing your password. This is useful for mobile device sharing.

## Password Security

### Q: How long should my password be?
A: For maximum security, we recommend using passwords that are at least 12 characters long. Longer passwords are exponentially more secure against brute force attacks. Our generator supports up to 50 characters.

### Q: Should I use special characters?
A: Yes, including special characters (!@#$%^&*) in your passwords significantly increases their strength and makes them harder to crack. Our generator includes symbols by default.

### Q: Can I use the same password for multiple accounts?
A: No, you should never use the same password for multiple accounts. If one account is compromised, all your other accounts would be at risk. Use unique passwords for each account.

### Q: How often should I change my passwords?
A: It's recommended to change your passwords every 3-6 months, or immediately if you suspect a security breach. Also change passwords if you've used them on compromised websites.

### Q: What makes a password strong?
A: A strong password depends on:
- Length (12+ characters recommended)
- Complexity (mix of character types)
- Randomness (avoid patterns or personal information)
- Uniqueness (different for each account)

## Memorable Passwords

### Q: Can I create memorable passwords?
A: While PasswordMonkey focuses on random passwords for maximum security, you can create memorable passwords by:
- Using longer passwords (16+ characters)
- Including a mix of character types
- Avoiding common words or patterns
- Using our generator with custom settings

### Q: What's the difference between random and memorable passwords?
A: Random passwords are stronger against attacks but harder to remember. Memorable passwords are easier to recall but may be slightly less secure. For the best security, use a password manager to store random passwords.
